# Margin 0.5.0 实现与验收记录

日期：2026-10-02。基于 [0.4.0 复审](review-0.4.0-2026-10-02.md)，修复全部审查问题并增加持续阅读与恢复工作流。按用户要求在此收尾提交、推送并同步 Mac；剩余实机验收见 [Mac 续接说明](continue-on-mac-0.5.0.md)。

## 修复范围

| 审查项 | 实现 |
| --- | --- |
| S1 旧目标写入覆盖新字段 | 等待目标路径锁以前捕获源/卡片凭据，真正 Repository 提交时复查；过期写入可见拒绝。 |
| S2 旧核验误删迁移后标注 | 删除提交出队后再次核对源身份/字段/卡片与 pending，返回实际删除的 ID。 |
| S3 缩略图预算阻塞正文 | 持续观察可见窗口、离屏回收/返回重绘、两并发、缩略图额度与复制预留；底层 raster 真正结束后才释放运行中画布。 |
| S4 自产大备份无法回读 | 公开备份导出、JSON解析和文件入口统一支持 64 MiB UTF-8；私有原件保护不受公开导出上限影响。 |
| S5 文献冲突处理不一致 | 明确选择有效条目，显示应用/跳过数量；最终提交重新验证来源身份和预览版本。 |
| S6 历史跨页位置偏移 | 保留有符号页内偏移，覆盖跨页/混合页面尺寸。 |
| T1/T2/T3 | 恢复选中样式、分页焦点限定当前结果、书名恢复非标题元素。 |
| 既有表格草稿丢失 | 按书目/字段/版本保留草稿，旧保存成功或失败不会覆盖新输入；错误可重试原操作。 |

## 新增工作流

- 恢复快照清单、容量统计、按数量或天数的清理预览与二次确认；保护最新可用自动快照、手工/恢复前/归档/未知/损坏内容，执行前校验目录身份和 SHA-256。
- 逐对象恢复差异与选择：同一标注的高亮、评论、卡片、待写意图和删除记录成组处理，active/deleted 冲突要求显式选择。
- 文献逐项勾选、跨页保留选择、批量确认唯一 vault 附件候选，明确跳过冲突和未确认路径。
- 阅读列表重命名与删除确认，书架视图/组合筛选/页码保存与重开恢复；保存失败重试，关闭前等待最新提交。
- 精确阅读位置持久化与命名书签增删改/跳转；按稳定 bookId 写入，重命名不把迟到保存写给另一书。
- PDF 印刷页码显示、跳转、引用与 `pageLabel` 摘录模板变量；`#N` 明确指定物理页，重复标签要求消歧。标注/链接物理页索引不变。
- 源文件变化与锚点诊断：新摘录携带与打开的 PDF 对应的文件 stat，旧数据或读取期间变化标为未知；抽屉可折叠查看并按引文搜索，不自动移动坐标。

模块职责见 [模块说明](enhancement-modules.md) 和 ADR 0008–0014、0016。
