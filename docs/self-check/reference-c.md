- 任务边界：只读参考目录中的 17 张 PNG；只写本文件，不修改源码、总 control-map、旧 bookshelf 或 OpenCodian。
- 观察方式：通过 `view_image` 逐张读取原图（每批最多 4 张），没有以文件名或 contact sheet 替代观察。
