Reading Desk 设置

书架、阅读器和标注共用同一份本地数据。

书库文件夹

Reading Desk 从这些文件夹自动发现 PDF 与 EPUB。

文件夹列表

用英文逗号分隔;修改后从书架「扫描书库」或命令面板重新扫描。

豆瓣元数据

从 book.douban.com 补全作者、评分与封面;只补空白字段,从不覆盖人工修改;低置信结果在书卡上标记「待确认」。

启用豆瓣刮削

串行低速请求豆瓣公开页面;当日被限流(HTTP 403)后自动暂停,明天恢复。

新书自动刮削

扫描入库、缺少书目来源的新书自动进入刮削队列。

全部标记待确认

即使是高置信命中,也在书卡上标记「待确认」,由你逐本核对。

刮削缺失信息的书目

为缺作者、缺封面或标题仍是文件名的存量书目逐本刮削;已有人工内容不受影响。

阅读偏好

目录样式即时作用于已打开的 PDF 导航;滚动模式与夜间纸面反相对新打开的阅读器生效,已打开的阅读器可在其工具栏「显示选项」中即时调整。

目录样式

控制 PDF 导航中的章节层级呈现,不改变 PDF 或摘录数据。

滚动模式

连续滚动把整本书排成一条虚拟长卷;单页一次只显示一页。

夜间纸面反相

在深色主题下把 PDF 纸面反相为夜间阅读底色,界面本身不受影响。

Markdown 图床

开启后在 Markdown 编辑器粘贴图片时自动上传,并以外链插入。

启用对象存储

裁剪图片与图床上传的总开关;凭据保存在本地插件数据中。

接管 Markdown 粘贴

需先启用对象存储。

对象存储凭据

填写 OSS 或 COS 的访问信息,可先用只读请求测试连通。

发送当前选区

在阅读器中选中原文后,通过命令「将当前 Reading Desk 选区交给 AI」把上下文交给已启用的兼容插件。

导入与导出

导入只读取旧数据并新建文件,不会覆盖仓库内容。

导入旧 Bookshelf 数据

导入旧 Bookshelf 的书目与分类;不会修改旧插件数据。此操作在当前库中只能执行一次,执行前需要二次确认。

导出当前书架

下载当前书架的 Markdown 或 JSON 清单。书架导出仅包含书目与分类;标注、评论与摘录状态请使用完整备份。

旧 Bookshelf 导入状态:此库尚未导入,可执行一次导入。
